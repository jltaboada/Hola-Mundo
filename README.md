# 🚀 Hola Mundo

> Mi primera página web: un sencillo «¡Hola, Mundo!» construido únicamente con **HTML**, **CSS** y **JavaScript**. Sin frameworks, sin dependencias, sin complicaciones.

🌐 **[Ver la web en vivo](https://jltaboada.github.io/Hola-Mundo/)**

---

## ✨ Características

- 🌓 **Tema oscuro moderno** — paleta basada en la de GitHub Dark, pensada para descansar la vista
- ⚡ **Cero dependencias** — tres archivos planos: ábrelos en el navegador y funcionan
- 📱 **Responsive** — se adapta a móvil, tablet y escritorio con CSS puro
- ⌨️ **Efecto máquina de escribir** — el título se escribe solo al cargar la página
- 🧮 **Demo interactiva** — un contador en JavaScript cuyos números pares cambian de color

## 📁 Estructura del proyecto

```
Hola-Mundo/
├── index.html    ← Estructura de la página (secciones, contenido)
├── styles.css    ← Estilos: tema oscuro, layout, animaciones
├── script.js     ← Interactividad: máquina de escribir, contador, año actual
└── README.md     ← Este archivo
```

## 🛠️ Tecnologías

| Tecnología | Uso |
|---|---|
| HTML5 | Estructura semántica (navbar, hero, secciones, footer) |
| CSS3 | Variables, Grid, `clamp()`, `backdrop-filter`, animaciones |
| JavaScript (vanilla) | Efectos interactivos, sin ninguna librería externa |

## 💻 Cómo ejecutarlo localmente

No hace falta instalar nada:

1. Clona el repositorio:
   ```bash
   git clone https://github.com/jltaboada/Hola-Mundo.git
   ```
2. Abre `index.html` en tu navegador. ¡Ya está! 😄
